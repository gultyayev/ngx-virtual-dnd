# Design System (demo + docs)

The docs site and the demo app follow the **Night** design system (neutral grounds, one accent, orange only for the item in hand; light and dark): https://claude.ai/artifact/178zESCbcsVoQpsAPpKqAf. Read it with the Artifact tool, starting with `project/README.md`; `project/rspress.md` maps it onto Rspress and, in its "Demo app" section, maps the demo's classes onto Night's components (`components/<Name>/`, `components/bundle.css`). Read Night before styling demo pages, docs pages or the docs theme.

The v1 **ngx-virtual-dnd Design System** (teal accent) in the project skill (`.claude/skills/ngx-virtual-dnd-design/`) is superseded; its logo assets (`assets/`) are still the shipped favicon and lockup.

## Rules for this repo

1. **Tokens:** both carry Night's `tokens.css` blocks, copied from the design system (never retyped): the demo in `src/styles/tokens.css` (imported by `src/styles.scss`, via `@use`), the docs at the top of `docs/theme/index.css`. The demo's file also maps the v1 variable names (`--bg`, `--border`, `--ink-2`, `--accent-soft`, …) onto Night (the v1 table in `rspress.md`) for the docs live examples and the smaller demo pages; use the Night names in new code. Never hard-code token hex values in components (the only literal colours are those Night's `components/bundle.css` uses, such as the dark held preview fill `#17202d`).
2. **Themes:** the demo sets `data-theme` (`light` or `dark`) on `<html>` (`ThemeService`, from the top bar's system/light/dark button, inside a view transition); before that, the dark tokens follow `prefers-color-scheme`. Rspress toggles `html.rp-dark` (and `html.dark`); the docs' dark Night block keys on `html.rp-dark`.
3. **Shared demo classes** (placeholder, drag preview, list/row styles used across pages) go in `src/styles.scss`, because the preview and placeholder render outside component views. The docs live examples share styles through `src/app/examples/examples-shell.scss` (unencapsulated, scoped to `app-examples-shell`), so the example components stay copy-pasteable.
4. **Docs theme overrides** (`docs/theme/index.css`): prefer mapping tokens onto `--rp-*` variables. BEM overrides must be prefixed with `html` to outrank Rspress's equal-specificity rules. Code blocks are dark in both themes.
5. **No emoji, no marketing tone.** Gradients only where Night allows them: the hero headline highlight, the hero glows (the docs hero and the demo's title band) and the dark list panel. List rows are inset cards inside a box that is exactly `itemHeight` tall; the active drop zone's card takes an `accent-line` edge with a 3px `accent-tint` halo (the fill does not change); the placeholder is the slot (1.5px dashed `accent-line` on `accent-tint`); the drag preview is the row at its exact size, never tilted or scaled, with a 1.5px `held` edge and `shadow-lift`.
6. **Accessible contrast:** all text meets WCAG AA against its background, in both themes.
