features:
  - title: Built for virtual lists
    details: Hit-testing and drop positions are computed from geometry, not from sibling DOM nodes, so drops land correctly on rows that are not rendered.
  - title: Dynamic item heights
    details: Rows are measured with ResizeObserver and cached by ID. Lookups use prefix sums and binary search.
  - title: Multiple lists
    details: Move items between any lists in the same group, with edge auto-scroll while dragging.
  - title: Keyboard and touch
    details: Space to pick up, arrow keys to move, Escape to cancel. Touch drags support a hold delay so lists still scroll.
  - title: Signals first
    details: Standalone components and directives for Angular 21 and 22. Drop events plus small helpers update your signal-based state.
  - title: Guides for AI assistants
    details: An installable agent skill and llms.txt give coding assistants the same guidance as these docs.
