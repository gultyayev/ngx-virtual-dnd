# Styling

The library ships no visual styles for items or lists. Its only built-in style is a `grabbing` cursor over lists and items (`vdnd-droppable` and `vdnd-draggable` elements) during mouse and keyboard drags. The rest of the page keeps its cursor, and so do elements inside items and lists that set their own `cursor` (a drag handle with `cursor: grab`, a button); the `pointer-events: none` recipe below covers those inside items. Touch drags get no cursor. Everything else is state classes that you style however you like.

## Classes

| Class                                                    | On                                  | When                                                 |
| -------------------------------------------------------- | ----------------------------------- | ---------------------------------------------------- |
| `vdnd-draggable`                                         | Draggables                          | Always                                               |
| `vdnd-draggable-dragging`                                | Draggables                          | While being dragged (the element is `display: none`) |
| `vdnd-draggable-disabled`                                | Draggables                          | `disabled` is true                                   |
| `vdnd-drag-pending`                                      | Draggables                          | `dragDelay` has passed, drag not started yet         |
| `vdnd-droppable`                                         | Droppables                          | Always                                               |
| `vdnd-droppable-active`                                  | Droppables                          | The pointer or keyboard target is this droppable     |
| `vdnd-droppable-disabled`                                | Droppables                          | `disabled` is true                                   |
| `vdnd-drag-placeholder`, `vdnd-drag-placeholder-visible` | Drop-position placeholder           | During a drag, in the target list                    |
| `vdnd-drag-preview`                                      | Preview box                         | During a drag                                        |
| `vdnd-drag-preview-dropping`                             | Preview box                         | While it plays the drop animation                    |
| `vdnd-overlay-container`                                 | Body-level container of the preview | After `<vdnd-drag-preview>` renders                  |
| `vdnd-dragging`                                          | `<body>`                            | While any drag is in progress                        |
| `vdnd-dragging-touch`                                    | `<body>`                            | While a touch drag is in progress                    |

`<vdnd-sortable-list>`, `<vdnd-virtual-scroll>`, `<vdnd-virtual-viewport>`, `<vdnd-virtual-content>`, `vdndScrollable` and `<vdnd-placeholder>` also carry their own name as a class (for example `vdnd-sortable-list`).

## Recipes

Highlight the list under the pointer. With `<vdnd-sortable-list>` the droppable is an inner element, so target it through the list:

```css
.vdnd-sortable-list .vdnd-droppable-active {
  background: #e4f3f2;
  box-shadow: inset 0 0 0 2px #0e9488;
}
```

Show a grab cursor on hover, and stop hover styles from firing on other rows during a drag:

```css
.vdnd-draggable {
  cursor: grab;
}

body.vdnd-dragging .vdnd-draggable {
  pointer-events: none;
}
```

Show the grabbing cursor over the whole page during a drag, not only over lists and items. A rule on `body` alone is enough, because `cursor` inherits; it costs a style recalculation that grows with the size of the page each time a drag starts and ends. Avoid `body.vdnd-dragging *`, which restyles every element:

```css
body.vdnd-dragging:not(.vdnd-dragging-touch) {
  cursor: grabbing;
}
```

Give the preview some lift:

```css
.vdnd-drag-preview > * {
  border-radius: 12px;
  box-shadow: 0 18px 40px -18px rgb(20 28 46 / 0.3);
  transform: rotate(1.5deg);
}
```

Dim items that cannot be dragged:

```css
.vdnd-draggable-disabled {
  opacity: 0.5;
  cursor: not-allowed;
}
```

These selectors must be global, in `styles.css` or with `ViewEncapsulation.None`, because the preview and placeholder are rendered outside your component's view.
